# Brand assets

Put the project logo here as **`logo.png`** (or `logo.svg` / `logo.jpg` / `logo.webp`).

`src/components/Logo.tsx` picks it up automatically at build time and renders it
at the top-left of the sidebar. If no file is present, an inline SVG recreation
of the "ST · STEALTH TAP" mark is used instead.

Recommended: transparent-background PNG or SVG, at least 240 px tall.
